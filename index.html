Loop Sender: Privacy Policy

Last updated November 14, 2026

Loop Sender is a private tool used only by David Morse to email his own music loops to producers who have asked to receive them. It is not offered to the public, and it signs in only to David Morse's own Gmail accounts.

What it accesses

With the account owner's permission, Loop Sender uses the Gmail API to read the account's sent mail (to see which loops each recipient already received, so nothing is sent twice), to create drafts, and to send emails from that account. It reads loop files from the owner's own Dropbox.

How the data is used

Data is used only to decide which loops to send and to send them. It is never sold, shared, or used for advertising, and it is not used to train AI models. Google user data is handled in line with the Google API Services User Data Policy, including its Limited Use requirements.

Storage

A small record of what was sent (recipient address, file name, date) is kept in the owner's private Dropbox. Sign-in tokens are stored privately and can be revoked at any time from the Google account's security settings.

Removal

Anyone who no longer wants to receive emails can reply and ask to be removed, and they will be.

Contact

Questions: reply to any email from Loop Sender, or contact David Morse through beatstars.com/davidmorse.
